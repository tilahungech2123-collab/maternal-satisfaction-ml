# Maternal Satisfaction Prediction Using Machine Learning

This project focuses on maternal satisfaction with vaginal and cesarean section delivery care services in health facilities in Bahir Dar City, Northwest Ethiopia. It applies machine learning techniques, particularly Logistic Regression, to analyze factors associated with maternal satisfaction and predict satisfaction based on selected input features.

The application provides an interactive interface for exploring model predictions and reviewing model evaluation results. Its purpose is to support research, improve understanding of factors associated with maternal satisfaction, and demonstrate the application of machine learning in healthcare.

**Note:** Predictions are for educational and research purposes only and should not replace professional healthcare judgment.
